# Reference Matrix

This repository contains deterministic CI fixtures used to check runner compatibility across a small set of fixed cases.

## Interface

- Each run is selected by a 32-character lowercase hexadecimal case identifier.
- Jobs use fixed implementations and do not accept arbitrary commands.
- Generated materials are not published from this repository.
- The repository is not an authoritative record for any underlying work.

The contents are intentionally generic. Case meanings and any associated records are maintained elsewhere.
